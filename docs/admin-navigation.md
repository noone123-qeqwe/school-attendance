# Admin navigation

The admin portal uses five areas on desktop and mobile:

| Area | Tasks |
| --- | --- |
| Home | Daily overview, school calendar, announcements and notifications |
| People | Student registrations and records, teachers, guardians and administrators |
| Classes | Class schedules, subjects, enrollment, sections, terms, courses and departments |
| Attendance | Attendance records, reports, student QR codes, excuses, corrections and warnings |
| School & system | Profile, settings, access permissions, audit logs and maintenance |

Open one area at a time in the sidebar or the mobile Menu. Use **Find a page**
to search across areas, including familiar words such as instructor or faculty.
The header search uses the same allowed destinations. Super administrator tools
remain restricted; data-entry admins and auditors keep their existing access.

Each page has an **In [area]** menu to reach related pages. The dashboard starts
with four everyday tasks, today's attendance totals and links to review requests.
QR codes remain under Attendance rather than a prominent scanner button.

Settings use five expandable categories. Collapsing a category keeps its fields
in the same Save changes form. Validation opens the relevant category, and
server errors open all categories so corrections remain accessible. Report types
are selected from one list rather than nine separate tabs.

System version, database and readiness information is available under **System
details** in maintenance. Updates, backups and health remain separate views.

The shared admin styles preserve the school's existing maroon and gold palette,
with responsive forms, readable phone records and keyboard focus indicators.
Automated rendering and interaction checks cover the admin pages and permissions.
Visual browser checks still require browser access in Work settings.
